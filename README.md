# 3D Pinball Simulator (Tiny2D × TypeScript)

TypeScript と 2D物理エンジン「Tiny2D」を組み合わせ、擬似3D空間（ワイヤーフレーム＋テクスチャマッピング）で表現したレトロな3Dピンボールシミュレーターです。

視点をリアルタイムに傾けることで重力の方向が変化し、ボールの軌道が変わるギミックを搭載しています。

---

## 🎮 プレイ方法（操作方法）

キーボードの矢印キーを使って、フィールドの傾き（カメラ視点）を操作します。

| キー | 操作内容 |
| :--- | :--- |
| **`←` (左矢印)** | 盤面を左に傾ける（重力が左にかかる） |
| **`→` (右矢印)** | 盤面を右に傾ける（重力が右にかかる） |
| **`↑` (上矢印)** | 盤面を奥に傾ける（重力が奥にかかる） |
| **`↓` (下矢印)** | 盤面を手前に傾ける（重力が手前にかかる） |

### 🎯 ルール
* 画面内にあるすべてのピン（球体）にボールを当てると、ピンの色が変化します。
* **全37個**のピンすべてにボールを当てるとゲームクリア（GAME OVER 表示）となります。
* ボールが画面外（下部など）に落ちた場合は、自動的に上部からリスポーン（復活）します。

---

## 🛠️ 技術スタック & 特徴

* **言語:** TypeScript (Strict モード)
* **描画:** HTML5 Canvas (2D Context)
* **物理演算:** Tiny2D.js (2D剛体物理エンジン)
* **3D表現:** * 自作の3D行列演算（回転行列）による座標変換
  * ベクトル演算による法線計算および簡易ランバートシェーディング（陰影処理）
  * Zバッファに代わる、ポリゴンの奥行き（`cZ`）ソートによる正しい描画順（画家のアルゴリズム）の再現
